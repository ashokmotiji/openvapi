# OpenVapi - Free Vapi AI Alternative

Fully self-hosted, open-source real-time voice AI agent platform.

## Quick Start

1. Clone the repo
```bash
git clone https://github.com/ashokmotiji/openvapi.git
cd openvapi
```

2. Copy env
```bash
cp .env.example .env
```

3. Run with Docker
```bash
docker compose up --build
```

Open http://localhost:3000

**Note**: This is a starter. More features coming.
